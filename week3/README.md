# Week 3 - Supervised Learning

## Overview
Week 3 focused on supervised machine learning, progressing from the basic train/test workflow to regression, classification, multiple classification algorithms, model evaluation, and finally a complete real-world classification mini-project.

## Day 1
[Day 1](./day1/) introduced supervised-learning fundamentals and the train/test split, with emphasis on separating training data from unseen test data for fair evaluation.

## Day 2
[Day 2](./day2/) focused on Linear Regression and regression evaluation, connecting continuous-value prediction with suitable regression metrics.

## Day 3
[Day 3](./day3/) introduced Logistic Regression for binary classification and applied classification metrics such as Accuracy, Precision, Recall, F1-score, confusion matrix, and ROC-AUC.ٍ

## Day 4
[Day 4](./day4/) expanded classification to Decision Tree, Random Forest, Support Vector Machine, and k-Nearest Neighbors, then compared model behavior and performance using common evaluation metrics.

## Day 5
[Day 5](./day5/) completed an end-to-end IBM Telco Customer Churn classification project. The workflow included raw-data inspection, cleaning, EDA, leakage-safe preprocessing, a baseline classifier, five supervised-learning models, model comparison, confusion-matrix analysis, ROC-AUC, feature importance, and final model selection.

Notebook: [day5.ipynb](./day5/day5.ipynb)

## Week 3 Skills
- Supervised-learning workflow
- Train/test splitting and stratification
- Linear and Logistic Regression
- Decision Tree and Random Forest
- Support Vector Machine (SVM)
- k-Nearest Neighbors (k-NN)
- Categorical encoding and numerical scaling
- Scikit-learn `Pipeline` and `ColumnTransformer`
- Data-leakage prevention
- Accuracy, Precision, Recall, F1-score, and ROC-AUC
- Confusion-matrix interpretation
- Baseline comparison
- Model comparison and selection
- Feature importance and careful model interpretation

## Final Outcome
Week 3 ended with a complete supervised-learning pipeline on a real telecom dataset. The final project demonstrated how to move from raw customer data to a reproducible classification workflow, compare several models fairly, select a model using meaningful metrics, and translate evaluation results into the customer-churn context.
