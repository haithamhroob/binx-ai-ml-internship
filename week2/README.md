# Week 2 — Math Foundations and Exploratory Data Analysis

## Summary

Week 2 focused on the mathematical foundations used in machine learning and their practical application through exploratory data analysis.

The work covered descriptive statistics, probability, distributions, linear algebra, outlier detection, data visualization, correlation analysis, and data storytelling using real datasets.

## Daily Work

### Day 1 — Descriptive Statistics

Applied descriptive statistics to an automotive sensor dataset.

The analysis included:

- Mean, median, mode, range, variance, and standard deviation
- Quartiles and Interquartile Range
- Outlier detection using the IQR method
- Comparison of statistics before and after filtering
- Box plot visualization

### Day 2 — Probability and Distributions

Used NumPy simulations to study probability concepts and common distributions.

The work included:

- Experimental and theoretical probability
- Complement, addition, and multiplication rules
- Conditional probability
- Bayes' theorem
- Coin and die simulations
- Normal, uniform, and binomial distributions

### Day 3 — Linear Algebra for Machine Learning

Applied linear algebra concepts using NumPy and connected them to machine learning operations.

The work included:

- Vectors and matrices
- Dataset shapes
- Dot products
- Matrix multiplication
- Batch prediction
- Shape mismatch errors
- Vector magnitude
- Determinants, inverses, eigenvalues, and eigenvectors

### Day 4 — Exploratory Data Analysis Part 1

Performed an exploratory analysis on a music dataset.

The work included:

- Dataset structure and data-quality checks
- Missing-value and duplicate detection
- Target-class distribution
- Histograms and box plots
- IQR-based outlier detection
- Initial bivariate and correlation analysis

### Day 5 — Exploratory Data Analysis Part 2

Completed the Week 2 EDA by combining statistical analysis, visualizations, relationships, correlation, and written findings into a narrated notebook.

The work included:

- Univariate and bivariate analysis
- Scatter plots and grouped box plots
- Correlation matrix and heatmap
- Pairplot analysis
- Strongest feature relationships
- Data-storytelling conclusions
- Modeling considerations

Different real datasets were used during the week:

## Key Learning Outcomes

By the end of the week, I was able to:

- Select and interpret appropriate statistical measures
- Simulate and verify probability concepts using code
- Represent datasets and predictions using vectors and matrices
- Detect and investigate potential outliers
- Analyze individual variables and relationships between variables
- Use correlation carefully without assuming causation
- Communicate analytical findings through visualizations and Markdown explanations
