# Week 2 — Data Analysis and Exploratory Data Analysis (EDA)

## Summary
Week 2 focuses on exploratory data analysis with an automotive sensor dataset. The notebooks cover:
- Day 1: data loading, cleaning, and descriptive statistics
- Day 2: data visualization and feature exploration
- Day 3: additional numeric analysis and relationship exploration
- Day 4: EDA and initial data storytelling
- Day 5: correlation analysis, bivariate plots, and a complete EDA narrative

## Notes
- The primary dataset is OBD-II vehicle sensor data.
- Each day builds on the previous work, moving from basic cleaning and summaries to deeper relationship analysis.
- Day 5 is intended to present a complete EDA notebook with correlation, pairplots, and findings.
- Use the `README.md` file in each day folder for day-specific details and results.
- The Week 2 work is structured to support future modeling by identifying strong feature relationships and data quality issues.
