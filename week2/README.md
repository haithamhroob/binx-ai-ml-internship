# BinX Tech AI & ML Internship

## Week 2 — Math Foundations and Exploratory Data Analysis

### Summary

Week 2 focused on the mathematical foundations used in machine learning and their practical application through data analysis.

The work covered descriptive statistics, probability, distributions, linear algebra, exploratory data analysis, outlier detection, correlation analysis, and data storytelling using NumPy, Pandas, Matplotlib, and Seaborn.

## Daily Work

### Day 1 — Descriptive Statistics

Applied descriptive statistics to a real OBD-II vehicle dataset.

The work included:

- Inspecting the dataset and selecting the vehicle speed column.
- Handling missing speed values.
- Calculating mean, median, mode, range, variance, and standard deviation.
- Computing quartiles and the Interquartile Range.
- Detecting potential outliers using the IQR method.
- Comparing statistics before and after filtering.
- Visualizing the speed distribution using a box plot.

### Day 2 — Probability and Distributions

Used NumPy simulations to study basic probability concepts and common distributions.

The work included:

- Experimental and theoretical probability.
- Coin-flip and dice simulations.
- Complement, addition, and multiplication rules.
- Conditional probability.
- Bayes' theorem.
- Normal, uniform, and binomial distributions.
- Visualizing generated distributions using histograms.

### Day 3 — Linear Algebra for Machine Learning

Applied linear algebra concepts using NumPy and connected them to machine learning operations.

The work included:

- Representing individual samples as vectors.
- Representing a complete dataset as a matrix.
- Inspecting matrix shapes and transposes.
- Calculating dot products.
- Using matrix multiplication to generate predictions for multiple samples.
- Understanding shape-mismatch errors.
- Calculating vector magnitude.
- Working with determinants, inverses, eigenvalues, and eigenvectors.

### Day 4 — Exploratory Data Analysis Part 1

Performed an initial exploratory data analysis on a music-feature dataset.

The work included:

- Inspecting the dataset structure and data types.
- Checking missing values and duplicated rows.
- Removing five duplicated observations.
- Examining the target-class distribution.
- Analyzing numerical features using histograms and box plots.
- Detecting 16 tempo outliers using the IQR method.
- Performing bivariate analysis using scatter plots and grouped box plots.
- Creating a correlation matrix and identifying important feature relationships.

### Day 5 — Complete Exploratory Data Analysis

Applied the complete Week 2 analysis workflow to a real OBD-II vehicle dataset.

The work included:

- Inspecting and cleaning the vehicle dataset.
- Removing empty rows, empty columns, and duplicated records.
- Examining missing values in important vehicle sensor features.
- Calculating descriptive statistics for vehicle speed.
- Visualizing pressure, temperature, engine RPM, and speed distributions.
- Detecting potential engine RPM outliers using the IQR method.
- Examining the relationship between engine RPM and vehicle speed.
- Comparing speed distributions across common vehicle models.
- Creating a correlation matrix and identifying the strongest relationships.
- Using a pairplot to examine selected vehicle measurements.
- Writing a data-storytelling summary and modeling considerations.

## Datasets

Different datasets were used during the week:

- Generated NumPy data for probability simulations.
- Vehicle feature vectors for linear algebra examples.
