# BinX Tech AI & ML Internship

## Week 2 - Day 2: Probability & Distributions

### Summary

Practiced the main probability concepts used in data analysis and machine learning. NumPy simulations were used to compare experimental probabilities with theoretical values, verify the core probability rules, calculate conditional probabilities, apply Bayes' theorem, and visualize common probability distributions.

### Tasks Completed

- Used NumPy random functions for sampling, shuffling, and generating random values.
- Simulated 10,000 coin flips and compared the proportions of heads and tails.
- Simulated 10,000 die rolls and compared the experimental probability of rolling a specific number with its theoretical probability.
- Verified the complement rule using the probability of rolling 4 and not rolling 4.
- Applied the addition rule to overlapping events.
- Verified the multiplication rule using two independent coin flips.
- Calculated conditional probability from a small Pandas DataFrame.
- Applied Bayes' theorem and compared its result with the directly calculated conditional probability.
- Generated and visualized normal, uniform, and binomial distributions.

### Key Concepts

- Experimental and theoretical probability
- Complement rule
- Addition rule
- Multiplication rule for independent events
- Conditional probability
- Bayes' theorem
- Normal distribution
- Uniform distribution
- Binomial distribution
- Random seeds and reproducibility
