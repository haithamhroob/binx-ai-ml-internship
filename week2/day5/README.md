# BinX Tech AI & ML Internship

## Week 2 - Day 5: Complete Exploratory Data Analysis

### Summary

Applied a complete exploratory data analysis workflow to a real OBD-II vehicle dataset.

The dataset was inspected and cleaned, then important vehicle sensor features were selected for descriptive statistics, distribution analysis, outlier detection, bivariate analysis, correlation analysis, and data storytelling.

### Notes

- Inspected the dataset shape, columns, and data types.
- Removed completely empty rows and columns.
- Checked and removed duplicated records.
- Examined missing values in the vehicle sensor columns.
- Selected important pressure, temperature, engine RPM, and speed features.
- Calculated descriptive statistics for vehicle speed.
- Visualized feature distributions using histograms and box plots.
- Detected potential engine RPM outliers using the IQR method.
- Kept plausible RPM outliers because they may represent real driving conditions.
- Examined the relationship between engine RPM and vehicle speed.
- Compared speed distributions across common vehicle models.
- Created a correlation matrix and identified the strongest relationships.
- Used a pairplot to compare selected vehicle measurements.
- Summarized the main findings and modeling considerations.
