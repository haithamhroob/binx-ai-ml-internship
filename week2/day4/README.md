## Week 2 - Day 4: Exploratory Data Analysis (EDA)

### Summary

Explored a new dataset using Python to understand its structure, distribution, and quality before any modeling work. Used Pandas for data inspection and Seaborn/Matplotlib for visualization to identify patterns, missing values, duplicates, and outliers.

### Tasks Completed

- Loaded the dataset from the provided CSV file.
- Reviewed the dataset shape and previewed the first rows.
- Checked data types and summary statistics for the numeric columns.
- Identified missing values and duplicate rows.
- Performed univariate analysis using histograms and box plots.
- Detected outliers using the IQR method.
- Explored relationships between variables using scatter plots and a correlation heatmap.

### Key Concepts

- Exploratory Data Analysis (EDA)
- Data inspection
- Missing values
- Duplicate values
- Univariate analysis
- Outlier detection with IQR
- Bivariate and multivariate analysis
